# 페이지 안의 연결된 데이터베이스

이 기능은 Android65(code136065)·Windows65 로컬 설치 후보에 포함됐다. [README의 APK·Windows ZIP](../README.md)은 이 PC의 E 드라이브 전용이다. 태블릿에는 APK를 복사하고 Windows ZIP은 전체를 푼다. 전체 Office·Notion 기능 완료나 실기기 수용을 뜻하지 않는다.

일반 페이지에서 **블록 추가 → 연결된 데이터베이스 → 원본 선택**을 누른다. 선택한 DB의 첫 보기를 바탕으로 이 페이지의 보기를 만든다. 표·보드·목록·갤러리·달력·타임라인·차트와 기존 보기 설정을 사용한다.

항목·속성·행 본문·첨부의 변경은 원본 DB에 저장된다. 보기 형식·필터·정렬·그룹·표시 속성은 해당 페이지 블록에 저장된다. 같은 원본을 여러 곳에 연결하면 저장 후 다른 유휴 보기를 갱신하며, 다른 보기에서 편집 중인 초안은 유지한다. 이름을 바꾸어도 고정 문서 ID로 연결한다.

**보기 설정**에서 여러 조건을 AND·OR로 묶고, 정렬 기준을 여러 개 추가해 우선순위를 정할 수 있다. **적용**을 눌러 페이지의 보기만 바꾼다. [복합 필터와 다중 정렬](notion-feature-scope.md#데이터베이스-복합-필터와-다중-정렬)

페이지의 저장·뒤로가기·문서 열기는 연결된 편집을 먼저 저장한다. 미저장된 연결 DB가 있으면 그 블록을 없애는 작업과 상위 접기를 막고, 화면 밖으로 스크롤해도 초안을 유지한다. 원본이 삭제되거나 충돌·다른 판본으로 바뀌면 빈 DB로 대체하지 않고 오류와 재시도를 표시한다.

저장 실패 뒤 **초안 버리고 다시 읽기**를 선택하면 확인 창이 열린다. **취소**는 초안을 유지한다. **초안 버리기**를 누르면 저장하지 않은 항목·첨부 변경을 버리고 현재 원본을 다시 읽는다. 페이지의 보기 설정과 이미 저장된 원본 DB는 보존한다. 원본 DB 자체의 저장 이력을 되돌리는 작업과는 구분한다.

Markdown·HTML·PDF 내보내기는 원본 DB를 가리키는 참조와 정확한 블록 JSON을 보존하고, live DB 내용이 함께 내보내지지 않았음을 보고서에 기록한다.

## 다른 LLM에서 사용하기

기존 MCP 연결을 사용한다. `read_document`로 페이지 본문의 `linkedDatabaseData.noteId`와 `view`를 읽고, 그 원본 ID의 현재 DB 판본을 다시 읽는다. `database_query`의 `apply.view`에 블록의 보기 JSON을 보내면 원본에 등록되지 않은 페이지 전용 보기로도 계산한다.

페이지의 보기만 바꾸려면 페이지 본문 판본을 조건으로 `update_document`를 사용한다. 항목은 원본 DB의 본문 판본을 조건으로 `database_action`의 `set_cell`·`add_row` 등을 사용한다. 페이지와 원본은 서로 다른 판본이다. 조회에 전달한 보기와 원본 판본을 사용하며, 두 문서를 동시에 고정한 원자적 조회는 아니다. 필터는 표시 조건이며 원본 DB의 접근 권한을 제한하는 기능이 아니다.

계약은 [Notion 공식 연결 DB 안내](https://www.notion.com/help/guides/using-linked-databases)를 참고했다. 자체 모델·저장·화면 구현이며 다른 앱의 코드를 제품에 복사하지 않았다. [개발 계획](superpowers/plans/2026-11-07-linked-databases.md)과 `build/validation/linked-databases1`은 최초 소스 검증 기록이며 당시의 설치 파일 미포함 설명도 보존한다.

[build65 통합 기록](../build/validation/office-source-build65/checkpoint65.json)에는 새 설치 Rust DLL/SDK를 사용하는 실제 host FFI·stdio15PASS/0skip과 패키징 검증을 연결했다. 동일 소스의 전체 Flutter2043PASS/106skip·분석0은 앞선 실행을 재사용했다. 실제 외부 LLM 앱·S9+/S Pen·앱 GUI·두 실기기 Drive 사용은 아직 확인하지 못했다. 자세한 범위는 [검증 기록](mvp-validation.md)을 따른다.
