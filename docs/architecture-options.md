# 아키텍처 후보 — 미선정

먼저 두 후보의 입력·저장·복원을 같은 합성 노트로 검증합니다. 문서상 API 지원이나 기존 앱의 배포 여부만으로 우리 앱의 품질을 확정하지 않습니다. 출처는 [호환성 조사](compatibility-research.md)에 모았습니다.

## A. PWA로 독립 구현

장점:

- Windows와 모바일 브라우저에서 같은 웹 코드를 사용할 수 있습니다. Markdown·검색·링크 UI를 빠르게 비교하기에 적합합니다.
- 홈 화면 앱 경로를 검토할 수 있어 초기 사용 실험에서 네이티브 앱 서명 절차를 줄일 수 있습니다. 배포·호스팅은 이번에 하지 않습니다.
- Obsidian이나 StarNote 코드를 재사용하지 않고 자체 데이터 모델을 설계할 수 있습니다.

비용과 불확실성:

- 필압·기울기 API가 있어도 브라우저·OS·펜 조합의 샘플 품질, 팜리젝션, 지연은 미검증입니다.
- 오프라인 캐시와 IndexedDB/OPFS 같은 저장 후보는 파일 탐색기상의 개인 vault와 다릅니다. 저장소 축출·용량·사용자 데이터 삭제에 대비한 독립 백업이 필요합니다.
- 파일 선택·디렉터리 접근과 백그라운드 동기화 지원이 플랫폼마다 다릅니다. 앱이 열렸을 때 재시도하는 경로도 설계해야 합니다.
- 네이티브 수준의 펜 처리·PDF 편집·대용량 문서가 필요하면 구현/최적화 비용이 커질 수 있습니다.

## B. Flutter / Saber 확장

장점:

- Saber의 공개 Flutter/Dart 코드에서 필기 편집기·PDF 처리·플랫폼 배포 사례를 검토할 수 있습니다.
- 네이티브 앱 경로에서 파일/OS 기능과 펜 입력을 다룰 여지가 있습니다. 기존 필기 기반에 Markdown·노트 ID·연결 인덱스·AI 설명을 확장하는 후보입니다.

비용과 불확실성:

- Saber의 GPL v3 조건과 제3자 패키지·폰트·아이콘 조건을 먼저 검토해야 합니다. 포크 여부·기준 커밋·소스 제공 방식·고지 보존을 정한 후 통합합니다.
- Flutter 지원 플랫폼과 Saber에 필요한 기능/플러그인의 실제 동작 범위는 다를 수 있습니다. 자체 앱의 펜·PDF·키보드·파일 기능 검증이 필요합니다.
- Saber 데이터 모델과 Markdown/링크 모델의 결합, 기존 저장 형식의 마이그레이션, upstream 변경 추적에 비용이 듭니다.
- iOS 네이티브 빌드/서명은 macOS·Xcode 환경과 배포 경로 검토가 필요합니다. Windows 준비만으로 iPhone/iPad 설치가 완료되지는 않습니다.

Flutter를 쓰되 Saber 코드를 통합하지 않는 독립 구현도 가능하지만, 기존 필기 기능을 직접 개발하는 비용을 별도로 평가해야 합니다.

## 공통 설계 경계 — 제안

입력/화면 → 노트·페이지·획/Markdown 모델 → 로컬 저장·백업을 분리합니다. 링크·검색·그래프는 재구성 가능한 인덱스로, AI 설명과 StarNote 가져오기는 분리된 모듈로 둡니다. 파일 확장자·DB·웹 프레임워크·Markdown 엔진은 아직 정하지 않습니다.

사용자 선택에 따라 공개 GitHub는 코드·문서, Google Drive는 개인 필기·PDF·백업의 원격 저장 대상으로 분리합니다. 두 후보 모두 로컬 데이터 저장 계층과 Drive 전송 계층을 나눕니다. 단순 백업이라면 버전 있는 스냅샷 업로드/복원, 양방향 동기화라면 리비전·충돌 사본·삭제 표식·첨부 무결성·재시도까지 추가해야 합니다. 방식은 아직 미정이며 Drive 연동은 구현하지 않았습니다.

공개 앱 ID와 설정 예시는 저장소에 둘 수 있지만 계정별 토큰·client secret·서명 키는 제외합니다. 필요한 Drive 권한과 기기 보안 저장소는 추후 선택합니다. 이번에는 로그인·OAuth grant·credentials 생성·개인 자료 업로드를 하지 않습니다.

## 같은 기준으로 비교할 실제 기기 항목

- Windows: 사용할 PC·펜 디스플레이/스타일러스·브라우저, 키보드/마우스, PDF 주석 위치와 저장 경로.
- Android: 실제 StarNote 사용 기기·펜, 압력 변화·손바닥 접촉·줌 중 획 끊김, 강제 종료 뒤 복구.
- iPad: 모델·iPadOS·호환 Apple Pencil, 압력 지원 여부, 필기 지연, 앱 전환·절전·재시작·오프라인 복원.
- iPhone: 터치 선택·읽기·Markdown 편집·첨부 가져오기·복원. iPad용 펜 경험과 구분합니다.
- 모든 기기: 긴 문서·회전 PDF·충돌 편집·시계 차이·삭제 복구, 앱 종료 상태에서 동기화가 보장되지 않는 경우의 재개 동작.

결정 기준은 실제 필기 만족도와 데이터 보존을 우선하고, 개발 편의·서명 유지 비용·라이선스·향후 유지보수 비용을 함께 비교하는 것입니다. 현재 추천 후보를 사용자 선택으로 간주하지 않습니다.
