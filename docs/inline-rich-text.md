# 페이지 글자 서식과 링크

이 기능은 **build62 Windows ZIP·Android APK에 포함**됩니다. [현재 설치 후보](../README.md)의 링크는 이 PC 전용이며 GitHub에는 게시하지 않았습니다. 이전 build61에는 없습니다. 일반 페이지와 데이터베이스 행 본문에서 같은 편집기를 사용합니다.

1. 글자를 선택하면 해당 블록 아래에 서식 도구가 나타납니다.
2. 굵게·기울임·밑줄·취소선·코드·강조를 적용합니다. 좁은 화면에서는 도구줄을 가로로 스크롤합니다.
3. 링크 도구에서 http/https 주소를 넣거나 현재 저장소의 문서를 선택합니다. 기존 링크는 열기·변경·제거할 수 있습니다.
4. 서식 지우기는 선택 범위의 서식과 링크를 함께 제거합니다. 본문 글자는 유지됩니다.
5. 자동 저장과 상단 저장·실행 취소·다시 실행을 사용합니다. Windows에서는 Ctrl+B/I/U, 지원하는 키보드에서는 Meta+B/I/U도 사용할 수 있습니다.

한글 조합 중 서식 명령은 조합 완료 뒤 적용합니다. 선택 범위가 이모지나 결합 문자 중간에 걸리면 해당 글자 전체에 적용합니다. 텍스트만 선택하거나 커서를 옮기는 동작은 저장 이력을 만들지 않습니다. 페이지 본문과 별도로 작성한 Markdown 요약도 유지합니다.

본문·제목·목록·인용·접기와 표/미디어 설명에 적용합니다. 표 셀, 코드 블록, 수식, 문서 링크 블록과 알 수 없는 블록의 범위 서식은 후속 범위입니다. 지원 블록을 다른 종류로 바꾸면 기존 서식 데이터는 보존되며, 지원 종류로 돌아올 때 다시 표시됩니다. 내보내기는 표시하지 않은 서식을 변환 보고서에 기록합니다.

선택한 페이지·DB를 Markdown·HTML·PDF로 내보내면 지원 서식과 링크가 반영됩니다. 첨부와 원본 JSON도 ZIP에 함께 보존합니다. 지원 글꼴에 없는 PDF 문자는 코드와 경고를 남깁니다. 전체 vault 내보내기·범위 서식이 있는 표 셀·Notion 전체 기능의 완료를 뜻하지 않습니다.

새 서식을 사용하는 페이지/행 본문은 version3으로 저장합니다. 구 version1/2 문서는 계속 읽지만 구 앱은 version3을 읽지 못합니다. 일반 저장과 실행 취소는 이미 사용한 형식 버전을 유지합니다. 해석할 수 없는 이전 metadata가 승격을 막으면 해당 데이터는 보존하고 새 서식 동작을 제한합니다.

다른 LLM은 기존 MCP `read_document`·`update_document`로 같은 서식을 읽고 편집합니다. [MCP 데이터 형식](mcp-setup.md)과 [구현·검증 계획](superpowers/plans/2026-11-06-inline-rich-text.md)을 참고하세요. 실제 외부 LLM 앱 등록과 S9+ 실행 수용은 별도입니다.
