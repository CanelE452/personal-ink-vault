# 223 도구 패널 — 짧은 설계

2026-11-15. 사용자 승인: "그 순서로". StarNote 기능 묶음 순서(223 도구 패널 → 224 도형 → 225 암기 테이프 → 226 손가락 탭)에 대한 답이다. 근거는 사용자가 보낸 StarNote 화면 16장과 `_docs/notes/starnote-tools.md`의 대조 결과다.

## 왜

- StarNote는 고른 도구를 한 번 더 누르면 그 도구의 패널이 뜬다. 볼펜·형광펜·지우개·올가미가 그렇다.
- 우리 앱 상태:
  - 펜·연필·형광펜만 한 번 더 누르면 툴바 아래로 옵션 줄이 펼쳐진다(굵기, 펜 종류). 지우개는 누를 때마다 직전 도구와 번갈아 바뀌고, 올가미는 옵션이 없다.
  - 엔진에는 있는데 켤 곳이 없는 설정이 있다. Saber 설정 화면 경로가 작업 화면으로 돌려보내지기 때문이다(`lib/main.dart` 158–161).
    - 지우개 자동 해제(`stows.disableEraserAfterUse`)
    - 거의 곧은 획을 직선으로(`stows.autoStraightenLines`, 형광펜 전용이 아니라 모든 펜에 적용)
    - 도형 인식 지연(`stows.shapeRecognitionDelay`)
    - 펜이 감지되면 손가락 그리기 끄기(`stows.autoDisableFingerDrawingWhenStylusDetected`)
  - 지우개 크기(`Eraser(size)`)와 획 안정화(펜 설정의 streamline, 기본 0.5)도 엔진에만 있다.

## 고른 방법

- 세 가지를 비교했다:
  1. 지금 옵션 줄을 넓힌다. 작지만 한 줄이라 슬라이더와 스위치 이름을 붙이기 어렵다.
  2. StarNote처럼 도구 옆에 뜨는 패널 카드를 만든다. 고른 방법이다.
  3. 아래에서 올라오는 시트. 219 툴바 설정과 같지만 필기 화면을 가린다.
- 고른 이유: 사용자가 보낸 화면이 그 모양이고, 제목·슬라이더·스위치를 이름과 함께 넣을 자리가 있다.

## 동작

- 여는 법:
  - 고른 펜·연필·형광펜·지우개·올가미를 한 번 더 누르면 패널이 뜬다.
  - 툴바가 위에 있으면 아래로, 아래에 있으면 위로, 옆에 있으면 옆으로 뜬다.
  - 바깥을 누르거나 그 도구를 다시 누르면 닫힌다.
  - 지금의 펜 옵션 줄은 이 패널로 바뀐다.
- 지우개 동작이 바뀐다:
  - 지금: 고른 지우개를 다시 누르면 직전 도구로 돌아간다.
  - 바뀐 뒤: 다시 누르면 패널이 열린다(StarNote와 같음). 직전 도구로는 그 도구를 눌러 돌아가거나 "자동 해제"를 켠다.
  - Ctrl+E는 지금처럼 번갈아 바꾼다.

## 패널 내용

- 펜(만년필·볼펜·도형 펜): 펜 종류 3개, 굵기, 획 안정화 0–100%(streamline). 도형 펜은 안정화가 0으로 고정이라 슬라이더를 감춘다.
- 연필: 굵기, 획 안정화.
- 형광펜:
  - 굵기.
  - 직선 그리기(새로 만듦): 켜면 형광펜은 늘 시작점에서 끝점까지 곧은 선이 된다. 그리는 중에도 곧은 선으로 보인다.
- 지우개:
  - 크기(새 저장값).
  - 형광펜만 지우기(새로 만듦): 켜면 형광펜 획만 지운다.
  - 자동 해제(기존 `disableEraserAfterUse`): 지우고 나면 직전 도구로 돌아간다.
- 올가미:
  - 자유 올가미 / 사각형 올가미(새로 만듦): 사각형은 누른 곳에서 뗀 곳까지의 직사각형이다.
  - 선택 대상(새로 만듦): 손글씨, 형광펜, 사진 스위치.
- 툴바 설정(219 시트)에 "필기" 묶음을 더한다:
  - 거의 곧은 선을 직선으로(`autoStraightenLines`)
  - 도형 인식 지연(`shapeRecognitionDelay`)
  - 펜이 감지되면 손가락 그리기 끄기
- 내보내기:
  - 툴바의 내보내기 버튼(지금은 SBA·PDF·PNG 버튼 줄)이 대화상자를 연다.
  - 대화상자 항목: 형식(PDF / 사진(지금 쪽 PNG) / 원본 .sba), 파일 이름(기본값은 노트 제목, 지금은 늘 "main"), 배경 포함(PDF·사진), "내보내기 및 공유".
- 새 저장값(`lib/data/prefs.dart`): 지우개 크기, 형광펜만 지우기, 형광펜 직선, 올가미 모양, 올가미 대상 3개.

## 하지 않는 것

- 무한 노트: 펜·지우개·올가미가 따로 만든 엔진이라 이번에는 PDF·페이지 노트만 바꾼다. 무한 노트는 다음 묶음에서 같은 패널을 붙인다.
- 엔진에 없는 기능: 점선·파선 펜, 픽셀·영역 지우개, 압력 지우개, 문질러 지우기, 정밀 올가미, 펜 상자(프리셋), 편집 가능한 PDF.
- StarNote의 그림(펜 일러스트 등)은 쓰지 않는다. 우리 아이콘과 글자를 쓴다.

## 판정 지표

- 태블릿에서 고른 도구를 한 번 더 누르면 패널이 뜨고, 바꾼 값이 다음에 노트를 열어도 남아 있다.
- 지우개 크기·형광펜만 지우기·사각형 올가미·선택 대상·형광펜 직선이 시험으로 확인된다.
- 내보낸 파일 이름이 노트 제목이다. 배경을 끄면 배경 없이 나온다.
- 기존 펜 굵기 시험(editor_width_presets_test 등)이 새 패널 구조에서도 통과한다.

## 위험

- 패널이 펜 입력을 가로챌 수 있다. 패널이 열린 동안 바깥을 누르면 닫히기만 하고 그리지 않게 한다.
- 지우개를 다시 누르면 패널이 열리는 것은 지금 습관과 다르다. 판정 때 사용자에게 꼭 알린다.
