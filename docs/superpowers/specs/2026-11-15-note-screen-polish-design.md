# 노트 화면 다듬기 (219) — 짧은 설계

2026-11-15. 사용자 승인: "그렇게 해"(219는 노트 화면 세 가지). 근거 자료는 `_docs/notes/ui-polish.md`.

## 왜

사용자는 앱이 "투박해서 사용하기 힘들다"고 했다. StarNote에서 좋다고 꼽은 동작은 다음 세 가지다.

- 툴바를 끌어서 옆에 붙이는 것
- 확대할 때만 배율이 보이는 것
- 노트 화면에 군더더기가 없는 것

이번 묶음은 노트 화면만 다룬다. 보관함은 220에서 다룬다.

## 목표

1. 배율 표시: PDF·페이지 노트와 무한 노트 모두, 배율이 바뀔 때만 화면 위 가운데에 작은 알약이 뜨고 잠시 뒤 사라진다. 알약에는 다음이 들어간다.
   - 배율(%): 누르면 배율 목록이 열린다.
   - 확대 잠금: PDF·페이지 노트만.
   - 되돌리기: PDF는 폭 맞춤, 무한 노트는 원점으로.
   스크롤이나 이동만으로는 뜨지 않는다.
2. 툴바 옮기기: 펜 툴바 끝의 손잡이를 끌면 화면 네 가장자리에 놓을 자리가 보이고, 놓은 쪽(위·아래·왼쪽·오른쪽)에 툴바가 붙는다. 위치는 기기에 저장되고 PDF·페이지·무한 노트가 같이 쓴다. 기본값은 지금처럼 위다.
3. 툴바 설정 버튼: 툴바에 톱니 버튼을 두고 "툴바 설정"을 연다.
   - 공통: 위치 선택, 전체 화면에서도 툴바 보이기.
   - PDF·페이지 노트만: 한 손가락 이동 잠금, 가로·세로로만 이동. 이 두 잠금은 원래 확대 표시와 함께 떠 있던 버튼에서 옮겨 온다.
4. 오류 문구: 사용자에게는 사람이 읽을 문장 한 줄만 보인다. 원래 오류와 앱 내부 경로는 "자세히"를 눌러야 보인다.
   - 대상: 작업 화면 알림(SnackBar), 보관함 오류 띠, 시작 오류, 문서 열기 실패 문구, Office 화면 오류 띠.

## 하지 않는 것

- 보관함 화면(220에서 다룬다)
- StarNote의 즐겨찾기 배율(☆)
- 툴바 도구를 고르거나 순서를 바꾸는 기능
- 데이터베이스·MCP 패널 오류 문구(따로 다룬다)

## 방법과 고른 이유

- 툴바 위치는 새 저장 값 `workspaceToolbarAlignment`(기본값 위)로 둔다. Saber의 `editorToolbarAlignment`는 기본값이 아래이고 사용자가 예전에 바꿨을 수도 있다. 이 값을 그대로 쓰면 업데이트 직후 툴바가 갑자기 아래로 갈 수 있다. 같은 이유로, 작업 화면이 Saber 값을 무시한다는 기존 시험은 그대로 둔다.
- 세로 툴바는 Saber에서 온 `Toolbar`의 세로 배치를 그대로 쓴다. 218에서 툴바 끝에 넣은 쪽 버튼도 같은 줄에 놓여 세로로 쌓인다.
- 끌어서 붙이기는 PDF·페이지 편집기와 무한 노트가 공유하는 새 위젯 하나로 만든다. 이 위젯이 툴바 배치, 손잡이, 놓을 자리 표시를 맡는다. 놓을 때는 손가락에서 가장 가까운 가장자리를 고른다.
- 배율 알약도 두 화면이 공유하는 위젯 하나로 만든다. 보이는 시간은 배율이 마지막으로 바뀐 뒤 2초다. 알약을 만지는 동안과 배율 목록이 열려 있는 동안에는 사라지지 않는다.
- 무한 노트 오른쪽 아래에 늘 떠 있던 "− 100% + 원점" 상자는 없앤다. "원점으로"는 무한 노트 툴바의 버튼으로 옮긴다.
- 오류 문구는 변환 함수 하나와 표시 위젯 하나로 처리한다.
  - 모든 오류는 메시지를 보여 준다. 개발자용 포장(예외 이름, "Bad state:", "PlatformException(…, null, null)")과 앱 내부 경로만 걷어 낸다.
  - 정해 둔 한국어 문장은 메시지가 비었을 때와 Dart 프로그래밍 오류일 때만 쓴다.
  - 원래 오류는 기록(log)에 남긴다.
  - (2026-11-15 수정) 처음에는 한글이 없는 메시지를 모두 일반 문장으로 바꿨다. 그런데 기존 시험 5개가 오류 메시지가 화면에 보이는 것을 요구했다. 앱도 FormatException·FileSystemException에 한국어 문장을 담아 던진다("변환한 PDF를 열 수 없습니다…"). 그래서 포장만 걷어 내는 방식으로 바꿨다.

## 확인 방법

- 위젯 시험:
  - 배율이 바뀔 때만 알약이 뜨고, 이동만으로는 뜨지 않고, 2초 뒤 사라진다.
  - 손잡이를 오른쪽으로 끌어 놓으면 툴바가 세로로 오른쪽에 붙고 위치가 저장된다.
  - 오류 문구에 "PlatformException"·"Exception:"·내부 경로가 보이지 않고, "자세히"를 누르면 보인다.
- 관련 기존 시험을 다시 돌린다. 이미 알려진 실패는 `memory/piv-known-test-failures`의 목록으로 분리한다.
- 219를 빌드해 태블릿에 설치하고, 우리 앱 화면만 캡처해 StarNote 화면과 나란히 비교한다.
