## 지금과 StarNote

- StarNote 펜 툴바 순서: 실행 취소·다시 실행 → 펜·형광펜·지우개·올가미 → 사진·글상자·도형·스티커·표 → 색 5개(바로 보임) → 굵기. 세로로 붙였을 때는 같은 순서로 세로로 쌓이고, 중간에 톱니가 있다.
- 우리 PDF·페이지 툴바(Saber):
  - 순서: 펜·연필·형광펜 → 색 열기 버튼 → 굵기 3개 → 올가미·레이저 포인터·지우개·사진·글상자·손가락 필기·전체 화면 → 실행 취소·다시 실행 → 내보내기 → 쪽 버튼(218).
  - 색은 버튼을 눌러야 줄이 하나 더 열린다.
  - 툴팁 일부는 영어로 나올 수 있다. Saber 문자열에 한국어 번역 파일이 없다 [추정, 화면 미확인].
- 우리 무한 노트 툴바: 따로 만든 툴바라 아이콘과 순서가 다르다.

## 하려는 것

1. 기본 순서를 StarNote처럼 바꾼다.
   - 위치: 손잡이 → 실행 취소·다시 실행 → 펜·연필·형광펜·지우개·올가미 → 사진·글상자 → 색 5개(바로 보임)와 색 더보기 → 굵기 3개 → 쪽 보기·쪽 추가 → 손가락 필기 → 전체 화면 → 툴바 설정(톱니).
   - 기본으로 숨기는 것: 레이저 포인터, 내보내기. 둘 다 편집에서 다시 켤 수 있다.
2. 툴바 편집: 툴바 설정 안에 "툴바 편집"을 둔다.
   - 도구마다 보이기 스위치가 있고, 끌어서 순서를 바꾼다. "기본값으로"도 있다.
   - 기기에 저장한다.
   - 손잡이와 톱니는 늘 보인다. 숨기면 설정으로 돌아올 길이 없어지기 때문이다.
3. 무한 노트 툴바도 같은 원칙(실행 취소 → 도구 → 색 → 굵기 → 기타)과 같은 편집 화면을 쓴다. 목록은 무한 노트 도구(이동, 원점으로, 저장 포함)다.
4. 툴바에 보이는 도구 이름은 한국어로 통일한다.

## 하지 않는 것

- StarNote에만 있는 새 도구(도형, 표, 스티커, 암기용 테이프, 태그). 원하면 하나씩 따로 만든다.
- 툴바 두 줄 배치.

## 확인 방법

- 위젯 시험:
  - 기본 순서
  - 숨긴 도구가 사라지고 다시 켜면 돌아온다
  - 순서를 바꾸면 저장되고, 다시 열어도 유지된다
  - 손잡이와 톱니는 숨길 수 없다
  - 세로 툴바에서도 같은 순서가 유지된다
- 219와 같은 체인(관련 시험 → 빌드 → 점검 → 설치)으로 확인한다.
