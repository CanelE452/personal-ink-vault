# Personal Ink Vault

손필기와 Markdown 지식을 한곳에서 연결하는 개인용 앱의 **준비 문서 저장소**입니다. Windows에서 개발을 시작하고 Android·iPhone·iPad·Windows에서 사용하는 것이 목표입니다.

현재 앱 코드·실행 파일·설치 절차는 없습니다. PWA와 Flutter/Saber 확장 중 어느 쪽도 확정하지 않았습니다.

공개 저장소: [CanelE452/personal-ink-vault](https://github.com/CanelE452/personal-ink-vault). 기본 브랜치는 `main`입니다.

## 목표

- 펜·형광펜·지우개·PDF 주석과 Markdown·수식.
- 고정 노트 ID를 이용한 링크·역링크·태그·검색·그래프.
- 필기 원본을 보존하면서 별도 영역에서 AI 설명을 읽고 작성.
- 오프라인 저장과 백업·복원을 먼저 검증한 뒤 기기 간 동기화 설계.

## 개발 저장소와 개인 데이터

GitHub는 공개 코드·문서 저장소로 사용합니다. 코드·설계·개인정보 없는 합성 테스트 자료만 관리하며, 개인 필기·PDF·백업의 원격 저장 대상은 Google Drive입니다. 오프라인 작업용 로컬 데이터도 코드 저장소 밖에 둡니다. 실제 `.note` 원본·첨부파일·인증정보를 Git에 넣지 않습니다. [.gitignore](.gitignore)는 실수 예방 장치이며 공개 전 파일 검토를 대신하지 않습니다.

GitHub 코드 관리와 노트 동기화는 별도 기능입니다. 공개 저장소를 만들거나 push해도 앱·Drive 연동·노트 동기화·백업·배포가 구현되는 것은 아닙니다. Drive를 단순 백업으로 쓸지 양방향 동기화로 쓸지는 미정입니다. 이번에는 새 계정·토큰·OAuth 권한을 만들거나 실제 자료를 업로드하지 않습니다.

## 현재 제한

- StarNote는 사용자 소유 `.note` 테스트 샘플을 기다립니다. 파싱·보기/변환·편집·왕복 호환은 모두 미검증입니다.
- 다른 앱의 라이브 파일이나 개인 노트를 수집하지 않습니다. 구독·인증 우회, 타인 데이터 추출, APK 무단 패치는 범위 밖입니다.
- Obsidian 앱은 무료이며 공식 Sync는 선택 유료입니다. 필요한 기능을 독립 구현하고 Obsidian 코드를 복제하지 않습니다.
- OSS 코드를 통합하기 전에 LICENSE와 의존성·자산·배포 조건을 검토합니다. 임의의 역공학 스킬을 설치하지 않습니다.

## 작업 위치

요청한 `E:\CODING\proj`는 존재하지만 이번 실행 환경의 쓰기 허용 경로 밖이므로 생성하지 않았습니다. 프로젝트는 지정 작업 공간 아래 `personal-ink-vault`에 준비했습니다. 기존 저장소·연구 작업은 수정하지 않습니다.
